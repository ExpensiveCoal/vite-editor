# V.I.T.E.
### Visual lightweIght Text Editor

## Warning

This project is still under construction and not fully functionnal yet.

## About

**VITE** is a light weight CLI text editor coded in rust.

## Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl + O` | Save and exit |
| `Ctrl + X` | Exit without saving |
