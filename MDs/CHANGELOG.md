
# Changelog

VITE is now a functional CLI text editor. You can type multiple lines of text and save them to a file. Editing existing text is not supported yet.

## [0.4.0] - 2026-11-28

### Added
- Added a CHANGELOG file.
- Added a CLI text editor that supports multiline text input and saving to files.

### Known Limitations
- Editing existing text is not supported yet.

## [0.3.1] - 2026-11-27

### Changed
- Changed the license from GNU GPL v3.0 to MIT.
- Improved error handling.
